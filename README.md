# 12 Prolog Practicals

This repository contains 12 separate Prolog source files based on the supplied practical list.

## Files
1. `Exp01_Knowledge_Base.pl` — student/course facts and relations
2. `Exp02_Arithmetic_Factorial_Fibonacci.pl` — arithmetic, factorial, Fibonacci
3. `Exp03_List_Operations.pl` — append, reverse, member, length
4. `Exp04_College_Timetable.pl` — timetable knowledge base
5. `Exp05_Student_Performance.pl` — topper/average/failed classification
6. `Exp06_Travel_Route_Recommendation.pl` — route recommendation
7. `Exp07_BFS_Shortest_Path.pl` — breadth-first search
8. `Exp08_DFS_State_Space.pl` — depth-first search
9. `Exp09_Hill_Climbing.pl` — hill climbing optimization
10. `Exp10_Expert_System_Fault_Diagnosis.pl` — rule-based diagnosis
11. `Exp11_Tic_Tac_Toe.pl` — Tic-Tac-Toe minimax
12. `Exp12_Water_Jug.pl` — Water Jug state-space search

## Run
Install SWI-Prolog, open a terminal in this folder, then start a file with:
```prolog
?- [Exp01_Knowledge_Base].
```
Run the example query written in each file's comments. File names are separate so each practical can be uploaded and tested independently.

Note: The provided table appears to swap the descriptions for Experiments 11 and 12 between its two description columns. This pack follows the detailed program-description column: Experiment 11 is Tic-Tac-Toe and Experiment 12 is Water Jug.
